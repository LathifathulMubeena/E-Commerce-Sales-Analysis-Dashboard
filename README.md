Ecommerce Sales Analysis Dashboard

### Project Overview

An Excel dashboard built for analysing ecommerce sales performance across products, customers, regions, and sales trends.

### Features

- Sales Overview
- Monthly Revenue Trend
- Product Performance
- Customer Analysis
- Regional Sales
- Profit Analysis
- Interactive Filters
